# Contributing

Outside contributions are not open yet. Pull requests to this repository
are not accepted for now.

You can still write your own block with the kit (see
[Packages/BlockKit/README.md](Packages/BlockKit/README.md)) and share it
from your own repository. A block is yours: the kit is MIT.
